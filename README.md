# Floppy Disk Media Website

A polished, responsive website for the Floppy Disk Media YouTube channel.

It showcases the channel focus on classic TV clips, DVD extras, adverts, and obscure media finds while using the channel brand colors and typography.

## Run / View Locally

Because this is a static site, you can open `index.html` directly in your browser, or serve it locally:

```bash
cd /home/runner/work/FloppyDiskMedia/FloppyDiskMedia
python3 -m http.server 8080
```

Then visit: `http://localhost:8080`

## Tech

- HTML5
- CSS3
- Google Fonts (Poppins)

## Brand Assets

Logos are stored in `/logos`, with the transparent `500x500 Icon No BG.png` used for prominent placements.
